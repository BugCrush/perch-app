# Security

Perch reaches into your Claude Code sessions, so security reports matter a lot to us.

**Please report a problem privately:** [open a private security advisory](https://github.com/BugCrush/perch-app/security/advisories/new) on this repository. Don't open a public issue for it.

Helpful to include: what an attacker could do, what they would need (on the same network, a paired phone, the relay only…), and steps to reproduce. Never include real invite codes, pairing links, tokens or keys; made-up ones are fine.

You'll get an answer within a few days. Fixes ship in a new release, and the advisory is published once people have had time to update.

Only the latest release is supported.
